# 🌾 開心農場

農場模擬遊戲，用瀏覽器開啟即可遊玩。進度存在 Firebase 雲端，需先登入。

🔗 **線上遊玩：** https://prayer168.github.io/happy_farm/

---

## 遊戲玩法

1. **登入** 後開始。可用 Google 帳號，或老師發的帳號密碼。進度自動存在雲端，換電腦登入就能繼續
2. **選種子** → **點農地種植**
3. 定時用 💧 **澆水**（超過澆水間隔會枯萎）
4. 成熟後用 🌾 **收穫** 或 **全部收穫**。點任何一塊成熟的地，會把所有成熟作物一次收完
5. 點 **賣出全部** 換取金幣、累積經驗值升等
6. 升等解鎖更多農地與高價作物

## 注意事項

| 危險行為 | 結果 |
|----------|------|
| 太久沒澆水 → 枯萎 → 再不澆 | 💀 缺水枯死 |
| 短時間內澆兩次水 | 🫧 溺斃（根部腐爛） |
| 施肥超過 2 次 | ☠️ 肥料中毒死亡 |
| 暴風雨天氣 | ⛈️ 每秒有機率損傷作物 |

## 天氣系統

| 天氣 | 效果 |
|------|------|
| 🌞 晴天 | 正常 |
| ☁️ 多雲 | 澆水間隔延長 15% |
| 🌧️ 下雨 | 每 25 秒自動澆水全部農地 |
| 🌵 乾旱 | 澆水間隔縮短 45%，更快枯萎 |
| ⛈️ 暴風雨 | 每秒 2% 機率損傷作物 |

## 多人遊玩

- 每位學生用自己的帳號登入，進度存在雲端，互不干擾
- 換電腦只要重新登入，就會載入上次同步的進度
- 老師用 Google 帳號進入管理頁，批次建立沒有 Google 帳號的學生帳號

## 技術

- 純 HTML / CSS / JavaScript（無建置步驟；雲端使用 Firebase JS SDK）
- Web Audio API 合成音效（無外部音訊檔）
- Firebase Authentication＋Firestore 雲端存檔（設定步驟見 [FIREBASE.md](FIREBASE.md)）
- 教學進度與音效開關仍只存在這台瀏覽器
- CSS Container Queries 實現農場格子完美正方形
- 全 RWD：桌機三欄 / 平板縮放 / 手機垂直堆疊
- GitHub Actions 自動部署 GitHub Pages
